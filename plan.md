# Курсова робота: Система автоматизації прокату автомобілів

## 1. Загальний опис проєкту
Веб-застосунок для автоматизації процесів оренди авто. Система має дві ролі користувачів (Клієнт та Адміністратор), інтерактивний каталог, систему відгуків, генерацію звітів та інтерактивну документацію API.

## 2. Стек технологій
- **Мова:** TypeScript (повна типізація фронтенду та бекенду)
- **Frontend:** React, Vite, Tailwind CSS, Axios
- **Backend:** Node.js, Express, TypeScript, bcrypt (хешування), jsonwebtoken (JWT)
- **База даних:** MySQL
- **ORM:** Prisma ORM
- **Документація:** Swagger (`swagger-ui-express`)

## 3. Схема бази даних (Prisma Models)
- **User**
  - `id` (Int, PK, AutoIncrement)
  - `name` (String)
  - `email` (String, Unique)
  - `password` (String)
  - `role` (Enum: USER, ADMIN, за замовчуванням USER)
- **Car**
  - `id` (Int, PK, AutoIncrement)
  - `brand` (String)
  - `model` (String)
  - `year` (Int)
  - `pricePerDay` (Float)
  - `isAvailable` (Boolean, за замовчуванням true)
  - `imageName` (String) -- назва файлу з папки public/images/cars/
  - `description` (Text)
- **Rental**
  - `id` (Int, PK, AutoIncrement)
  - `userId` (Int, FK -> User)
  - `carId` (Int, FK -> Car)
  - `startDate` (DateTime)
  - `endDate` (DateTime)
  - `totalPrice` (Float)
  - `status` (Enum: PENDING, ACTIVE, COMPLETED, CANCELLED)
- **Review**
  - `id` (Int, PK, AutoIncrement)
  - `userId` (Int, FK -> User)
  - `carId` (Int, FK -> Car)
  - `rating` (Int, від 1 до 5)
  - `comment` (Text)
  - `createdAt` (DateTime, за замовчуванням теперішня дата)

## 4. Структура сторінок (Фронтенд)
### Публічні сторінки (Доступні всім та Клієнтам):
- `GET /` — Головна сторінка. Каталог автомобілів (картки з фільтрацією за маркою/ціною).
- `GET /car/:id` — Детальна сторінка авто. Опис, список відгуків. Кнопка "Орендувати", яка відкриває модальне вікно вибору дат.
- `GET /login` & `/register` — Сторінки авторизації/реєстрації.
- `GET /profile` — Кабінет користувача. Історія його оренд та їхні статуси.

### Панель Адміністратора (Доступ лише для ADMIN):
- `GET /admin` — Дашборд. Картки з метриками (Всього клієнтів, Всього авто, Загальний заробіток).
- `GET /admin/cars` — Керування авто. Таблиця машин з можливістю видалення/редагування та кнопкою "Додати авто" (форма, де вказується текстове ім'я картинки).
- `GET /admin/rentals` — Керування замовленнями. Список усіх оренд із можливістю змінювати статус (наприклад, перевести з PENDING в ACTIVE). Кнопка "Завантажити звіт (CSV)", яка вивантажує файл усіх оренд для Excel.

## 5. Додаткові технічні вимоги
- Паролі користувачів в БД мають зберігатися виключно у вигляді хешу через `bcrypt`.
- Усі ендпоінти REST API мають бути задокументовані через Swagger і доступні за адресою `/api-docs`.
- Зображення автомобілів зберігаються статично у папці фронтенду `/frontend/public/images/cars/`.
